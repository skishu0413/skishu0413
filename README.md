## 🚀 Featured Projects

### 🧠 [Autonomous Cyber Defense Platform](https://github.com/skishu0413/Autonomous-Cyber-Defense-Platform)
- Built a RAG-backed multi-agent cybersecurity platform using Python, LangGraph, Qdrant, and multiple LLM providers
- Developed specialized Guardrail, Blue Team, Red Team, and DevSecOps agents for threat detection, prompt protection, adversary simulation, and vulnerability remediation
- Implemented fail-closed authorization, tamper-evident audit logging, security-event routing, and GitHub pull-request integration
- Created more than 300 unit and property-based tests to validate security and authorization behavior

### 🔍 [Agentic AI Security Platform](https://github.com/skishu0413/Agentic-Security-Platform)
- Developed a secure-code analysis platform for evaluating source code generated by AI systems
- Integrated AST-based detection, Bandit, CodeQL, MITRE CWE mapping, and multi-provider AI security reviews
- Built a FastAPI dashboard for executing scans, monitoring providers, and reviewing vulnerability findings
- Containerized the platform with Docker and generated standardized JSON reports for CI/CD and security automation

### 🤖 [AI-Based Threat Detection System](https://github.com/skishu0413/AI-Threat-Detection-System)
- Built a full-stack threat-detection application using React, Flask, PostgreSQL, and machine learning
- Applied Isolation Forest anomaly detection to identify suspicious authentication, network, and data-transfer activity
- Implemented JWT-based authentication, user-specific detection history, interactive charts, and CSV reporting
- Designed a responsive analyst dashboard using React, Tailwind CSS, Axios, and Chart.js

### 🛡️ [Network-Based Intrusion Detection System](https://github.com/skishu0413/Info_Security_Labs/tree/main/Network_based_IDS)
- Built a Snort-based intrusion detection environment for identifying malicious network activity and file transfers
- Created Python automation for parsing logs, filtering alerts, and transferring evidence between systems
- Detected FTP-based ELF exfiltration and executable content embedded in PDF files
- Applied packet inspection, custom signatures, and network-forensics techniques to investigate suspicious traffic
